# Bloomberg Terminal Design School

## 1. Philosophy
Maximal data density, uncompromising utility, and pure utilitarianism. The Bloomberg Terminal sacrifices conventional aesthetics and negative space for raw information throughput. The interface is optimized for muscle memory, rapid visual scanning by trained professionals, and absolute reliability under pressure. It is the antithesis of modern minimalistic "slop," demanding user expertise rather than coddling them.

## 2. Exact CSS Design Tokens
**Fonts:**
- Primary: `Arial, sans-serif` (Historically fixed-width or highly legible sans)
- Monospace: `Consolas, 'Courier New', monospace`
- Font Sizes: Extremely small (10px - 12px) to maximize data per square inch.

**Hex Colors:**
- Background: `#000000` (Pure Black)
- Text (Primary): `#FF9900` (Amber/Orange - optimized for contrast in dark rooms)
- Text (Secondary/Data): `#FFFFFF` (White)
- Positive Ticks/Up: `#00FF00` (Bright Green)
- Negative Ticks/Down: `#FF0000` (Bright Red)
- Borders/Separators: `#333333` (Dark Gray)

## 3. Spatial Reasoning & Grid
- **Grid System:** Absolute, rigid, tabular. No fluid responsive design; panels are rigidly defined and tile perfectly to avoid overlapping windows.
- **Spacing:** Minimum padding and margin (0px - 2px). Every pixel must serve a purpose.
- **Layout:** Split-screen panels, heavily compartmentalized.

## 4. Component Architecture & Physics
- **Components:** High-density data tables, sparklines, command-line interfaces integrated with GUI elements.
- **Physics:** Instantaneous. Zero animations or transitions. Changes happen synchronously with data ticks.

## 5. Anti-Slop Validation Checklist
- [ ] Is data density maximized?
- [ ] Are animations completely removed?
- [ ] Does it use high-contrast, pure-color text on a pure black background?
- [ ] Is there zero reliance on drop shadows, gradients, or border-radius?
- [ ] Is it fully controllable via keyboard commands without a mouse?
