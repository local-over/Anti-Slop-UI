# Monzo Design System

## 1. Philosophy
Straightforward Kindness, Everyday Magic, and Warm Wit. Monzo's design bridges the gap between a traditional banking utility and a modern, delightful lifestyle app.

## 2. Exact CSS Design Tokens
- **Fonts:** `Monzo Sans` / System UI (Clean, approachable geometric sans).
- **Hot Coral (Brand Iconography):** `#FD5A5F` (or similar neon coral variants).
- **Deep Navy (Primary Text/Headers):** `#14233C`
- **Action Blue:** `#0055FF`
- **Background:** `#F4F5F7` (Off-white canvas for physical card separation).
- **Success Green:** `#20A06D`

## 3. Spatial Reasoning & Grid
- **Cards as Physical Objects:** Heavy emphasis on the "card" metaphor. Account containers look and behave like physical credit cards.
- **Radii:** Soft but structured (12px to 16px).
- Generous padding to prevent accidental mis-taps on financial transactions.

## 4. Component Architecture & Physics
- **Semantic Tokens:** Built to seamlessly transition between Light and Dark mode using underlying semantic variables.
- **Micro-interactions:** "Magic moments" (e.g., particle effects on completing a saving goal or paying a friend).
- **Data Visualization:** Clean, instantly legible bar charts and spend summaries built with native vector shapes.

## 5. Anti-Slop Validation Checklist
- [ ] Does the tone of voice and micro-copy feel warm and straightforward?
- [ ] Are accounts and pots visually represented as physical, distinct cards?
- [ ] Is Hot Coral used to punctuate the UI rather than overwhelm it?
- [ ] Are financial data points (numbers, currencies) strictly aligned for rapid scanning?
