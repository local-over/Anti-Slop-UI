# 1. Philosophy
Radical transparency and retro-futurism. Nothing OS relies on dot-matrix typography, monochrome palettes, and showing the "bare metal" of the software. It strips away gradients and shadows for pure, raw graphics.

## 2. Exact CSS Design Tokens
```css
:root {
  --font-dot-matrix: 'NDot', monospace;
  --font-sans: 'Inter', sans-serif;
  --color-bg: #000000;
  --color-text: #FFFFFF;
  --color-red-accent: #FF0000;
}
```

## 3. Spatial Reasoning & Grid
- Brutalist grid layouts.
- Heavy use of borders and outlines to define containers.
- Prominent use of negative space to isolate dot-matrix headers.

## 4. Component Architecture & Physics
- Stuttery, retro motion for certain widgets, alongside 120Hz smooth scrolling.
- Instant toggle states.
- Hardware integration (Glyph interface) syncing with software alerts.

## 5. Anti-Slop Validation Checklist
- [x] Avoided "disruptive" and "revolutionary".
- [x] Described the dot-matrix aesthetic literally.
- [x] Kept it simple and direct.
