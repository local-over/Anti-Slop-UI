# PlayStation 5 UI Design School

## 1. Philosophy
Immersive, cinematic, and atmospheric. The PS5 interface aims to blend the operating system seamlessly with the game content. It uses light, particle effects, and high-fidelity assets to create a premium, next-generation spatial environment.

## 2. Exact CSS Design Tokens
**Fonts:**
- Primary: `SST, Sony Sketch, sans-serif` (Sleek, modern, sharp geometry).
- Weight: Thin (200) for massive headers, Medium (500) for readable text.

**Hex Colors:**
- Backgrounds: Dark, dynamic gradients based on game art. Base UI is `#000000` with varying opacity.
- Text: `#FFFFFF` (White)
- Accents: `#DBC882` (Gold/Premium) or `#00439C` (PlayStation Blue)
- Focus State: A subtle inner glow or high-contrast white border.

## 3. Spatial Reasoning & Grid
- **Grid System:** Small, top-left aligned icons (Control Center) leaving the majority of the screen free for 4K background art.
- **Spacing:** Extremely spacious. Minimal UI chrome.
- **Layout:** Layered Z-axis design. The UI feels like glass panes floating in front of immersive worlds.

## 4. Component Architecture & Physics
- **Components:** Frosted glass panels (backdrop-filter: blur), subtle glowing edges, microscopic iconography.
- **Physics:** Smooth, drifting animations. Elements fade and scale elegantly. The UI responds dynamically to the underlying game engine.

## 5. Anti-Slop Validation Checklist
- [ ] Is 80%+ of the screen dedicated to immersive background imagery?
- [ ] Does it use atmospheric particle effects and blurred glass?
- [ ] Are fonts thin, sharp, and highly legible against complex backgrounds?
- [ ] Does the UI feel like it exists in a 3D spatial environment?
- [ ] Are transitions cinematic and fluid rather than snappy?
